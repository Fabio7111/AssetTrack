# AssetTrack
O AssetTrack é um sistema web para gerenciar o ciclo de vida de equipamentos da Unimed Assis. Ele substitui controles manuais ao centralizar o cadastro, localização, manutenções e descarte de ativos. Com histórico completo e relatórios, a solução garante rastreabilidade, segurança e eficiência na tomada de decisões.
